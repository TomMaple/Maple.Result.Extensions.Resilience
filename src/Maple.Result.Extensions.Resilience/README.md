# Maple.Result.Extensions.Resilience

Resilience extensions for [Maple.Result](https://www.nuget.org/packages/Maple.Result): Retry-After metadata on errors
and helpers for retry policies.

This package is under development; see the
[repository](https://github.com/TomMaple/Maple.Result.Extensions.Resilience) for its status.
